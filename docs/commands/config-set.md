# jtt config set

Change a project's tracked field or units, without the questions of `jtt init`.

![jtt config set OPS --display-unit days, then jtt config show](gifs/config-set.gif)

```console
$ jtt config set OPS --display-unit days
$ jtt config set DATA --field customfield_10041 --unit days
$ jtt config show
```

Pass only what changes: the rest keeps its current value. A project not set up yet needs
`--field`; [`jtt fields`](fields.md) lists the ids. A Jira time tracking field always holds
seconds, so `--unit` is ignored for one, and a points field is always shown in points.
