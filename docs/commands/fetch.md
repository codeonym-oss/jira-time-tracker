# jtt fetch

List the issues touched in a period, with the tracked field's current value.

![jtt fetch for a week](gifs/fetch.gif)

```console
$ jtt fetch --from 2026-09-21 --to 2026-09-28
$ jtt fetch -p OPS --from 2026-09-21 --to 2026-09-28 --user me
```

These are the issues [`jtt calculate`](calculate.md) examines: updated since the period
started, and created before it ended. `fetch` stops there, without reading change histories,
so it is quick, and the values are today's, not what changed in the period.

With `--user`, only the issues that person held at some point in the period. `--json` prints
the query and Jira's raw answer instead of a table, for a script:

```console
$ jtt fetch --from 2026-09-21 --to 2026-09-28 --json
```
