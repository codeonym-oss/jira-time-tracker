# jtt fields

List the numeric fields a project can track.

![jtt fields -p DATA --counts](gifs/fields.gif)

```console
$ jtt fields -p DATA
$ jtt fields -p DATA --counts
```

These are the site's number fields, Jira's time tracking fields included. The ones on one of
the project's create screens are marked ★ and listed first: the field holding your estimates
is almost always one of them.

`--counts` adds how many of the project's issues hold a value in each ★ field, a quick way to
tell which one your team fills in. The ids go to [`jtt init --field`](init.md) or
[`jtt config set --field`](config-set.md).
