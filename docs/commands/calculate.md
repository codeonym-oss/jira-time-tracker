# jtt calculate

The net amount that came into being in a period, per issue, for the whole project or one
person.

![jtt calculate for a week, then one person's share](gifs/calculate.gif)

```console
$ jtt calculate --from 2026-09-21 --to 2026-09-28
$ jtt calculate --from 2026-09-21 --to 2026-09-28 --user daniel --attribution holder
```

Each row is an issue whose tracked field changed in the period, or that was created in it with
a value, and its net change. [How jtt counts](../guide/how-it-counts.md) explains where each
number comes from.

`--user` narrows it to one person. With the default `--attribution was`, their issues are the
ones they held at some point in the period, and every change on those counts. With
`--attribution holder`, only the changes made while they held the issue count
([whose work counts](../guide/how-it-counts.md#whose-work-counts)).

## More detail

```console
$ jtt calculate --from 2026-09-25 --to 2026-09-26 -v
$ jtt calculate --from 2026-09-25 --to 2026-09-26 -vv
$ jtt calculate --from 2026-09-25 --to 2026-09-26 -vvv
```

`-v` adds each issue's current value, type, status and assignee. `-vv` adds the unchanged
issues and a timeline of every change. `-vvv` adds the query sent to Jira, every API request,
and the changes outside the period
([levels of detail](../guide/how-it-counts.md#levels-of-detail)).

Time amounts can be shown in another unit for one report:

```console
$ jtt calculate -p OPS --from 2026-09-21 --to 2026-09-28 --as days
```
