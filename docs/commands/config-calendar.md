# jtt config calendar

Set the working day and week used to convert between hours, days and weeks.

![jtt config calendar --hours-per-day 7.5, then a report in days](gifs/config-calendar.gif)

```console
$ jtt config calendar --hours-per-day 7.5
$ jtt calculate -p OPS --from 2026-09-21 --to 2026-09-28 --as days
```

[`jtt login`](login.md) reads them from the site's time tracking settings (8 hours a day and 5
days a week, unless your Jira admin changed them). Set them when your team counts days
differently from the site. Points are never converted.
