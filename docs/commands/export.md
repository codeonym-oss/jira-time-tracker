# jtt export

Write a report to a file: CSV, JSON or Markdown.

![jtt export -k contributions to CSV, then the file](gifs/export.gif)

```console
$ jtt export -k contributions -o september.csv --from 2026-09-01 --to 2026-10-01
$ jtt export -k issues -o week.json --from 2026-09-21 --to 2026-09-28
$ jtt export -k daily -o week.md --from 2026-09-21 --to 2026-09-28
```

The file's extension picks the format, or `--format` does. CSV is written with a byte order
mark, so Excel opens accented names correctly; JSON and Markdown also carry the report's
settings: the project, field, unit, period, person and query.

`--kind` chooses what each row is:

`issues` (the default)
: One row per issue touched in the period: its value now, the value it was created with, its
  changes in the period and its net, as in [`calculate`](calculate.md).

`changes`
: One row per change in the period, with its time, author, the person holding the issue, and
  the value before and after.

`contributions`
: One row per person, as in [`contributions`](contributions.md).

`daily`
: One row per day of the period, with its net.

`--user` and `--attribution` work as in [`calculate`](calculate.md). An existing file is kept
unless you pass `--force`:

```console
$ jtt export -k contributions -o september.csv --from 2026-09-01 --to 2026-10-01 --force
```

## Options

<!-- options -->
<!-- Generated by scripts/cli_docs.py from the CLI: edit the help texts in cli.py. -->

```text
jtt export [OPTIONS]
```

| Option | Default | Description |
|---|---|---|
| `-o`, `--output` `PATH` | required | File to write; the extension picks the format. |
| `-k`, `--kind` `[issues\|changes\|contributions\|daily]` | `issues` | What each row is. |
| `-f`, `--format` `[csv\|json\|md]` |  | Override the format. |
| `-p`, `--project` `TEXT` |  | Project key; defaults to the one set by init. |
| `--from` `TEXT` |  | First day, included (YYYY-MM-DD). |
| `--to` `TEXT` |  | Last bound, excluded (YYYY-MM-DD). Defaults to tomorrow, so today counts. |
| `--period` `TEXT` |  | Named period instead of --from/--to: today, yesterday, this-week, last-week, this-month, last-month, this-quarter, last-quarter, this-year, last-7-days, last-30-days. |
| `-u`, `--user` `TEXT` |  | Account id, 'me', or part of a name or email. |
| `--attribution` `[was\|holder]` | `was` | As in calculate. |
| `--as` `[points\|seconds\|minutes\|hours\|days\|weeks]` |  | Show time amounts in another time unit. |
| `--workers` `INTEGER` | `8` | Parallel changelog requests. From 1 to 32. |
| `--force` |  | Overwrite an existing file. |
| `-h`, `--help` |  | Show the command's help and exit. |
